## Libraries & Packages

**[Uniswap Widget](https://github.com/houtanrocky/uniswap-widget)**
Embeddable Uniswap swap widget with a framework-agnostic core and React & Vue bindings. No token limits, no warning barriers, no interface fees.

Core: [@uniswap-widget/core](https://www.npmjs.com/package/@uniswap-widget/core) · React: [@uniswap-widget/react](https://www.npmjs.com/package/@uniswap-widget/react) · Vue: [@uniswap-widget/vue](https://www.npmjs.com/package/@uniswap-widget/vue)

**[Iranian Banks Icons](https://github.com/houtanrocky/iranian-banks-react-icons)**
Vector SVG icons for Iranian banks, credit institutions, and PSP gateways. Zero runtime dependencies, TypeScript-typed, MIT licensed.

Core: [@iran-utils/iranian-banks-icons-core](https://www.npmjs.com/package/@iran-utils/iranian-banks-icons-core) · React: [@iran-utils/iranian-banks-react-icons](https://www.npmjs.com/package/@iran-utils/iranian-banks-react-icons) · Vue: [@iran-utils/iranian-banks-vue-icons](https://www.npmjs.com/package/@iran-utils/iranian-banks-vue-icons)

**[Card to Sheba](https://github.com/houtanrocky/cardtoshaba)**
Validate Iranian debit card numbers and convert them to IBAN / Sheba format. Luhn checksum, IIN/BIN issuer lookup, standardized formatting.

## Chrome Extensions

**[Session Switcher](https://chromewebstore.google.com/detail/session-switcher/ibleijinnlbhcpkgcccfmakidclplgga)**
Run multiple isolated accounts side-by-side on any website, with separate cookie jars, localStorage, and IndexedDB per tab. Firefox-style container tabs for Chromium browsers.

**[Discord Chat Exporter](https://chromewebstore.google.com/detail/discord-chat-exporter/hecekgpcppmbmajfbmdmdnpjcnhofaoa)**
Export Discord conversations into portable formats. Built for large chat histories.

**[Kill Switch](https://github.com/houtanrocky/killswitchextension)**
IP-based website access control. Blocks sensitive domains when you are on an untrusted network. [Chrome Web Store](https://chromewebstore.google.com/detail/kill-switch-extension/nnnfldbklgnohjccmcgehkdknhnpijjd)

**[Udemy Course Insights](https://github.com/houtanrocky/chrome-extenstion-udemy-helper)**
Reveals the original creation date of Udemy courses, not just the last update. [Chrome Web Store](https://chromewebstore.google.com/detail/udemy-course-insights/ndcegcfnihfkgknkbhhckenmfdbpfiod)
