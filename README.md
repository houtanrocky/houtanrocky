## Libraries & Packages

**Uniswap Widget** — Embeddable Uniswap swap widget with a framework-agnostic core and React & Vue bindings. No token limits, no warning barriers, no interface fees.

[Repo](https://github.com/houtanrocky/uniswap-widget) · [Core](https://www.npmjs.com/package/@uniswap-widget/core) · [React](https://www.npmjs.com/package/@uniswap-widget/react) · [Vue](https://www.npmjs.com/package/@uniswap-widget/vue)

**Iranian Banks Icons** — Vector SVG icons for Iranian banks, credit institutions, and PSP gateways. Zero runtime dependencies, TypeScript-typed, distributed under MIT.

[Repo](https://github.com/houtanrocky/iranian-banks-react-icons) · [Core](https://www.npmjs.com/package/@iran-utils/iranian-banks-icons-core) · [React](https://www.npmjs.com/package/@iran-utils/iranian-banks-react-icons) · [Vue](https://www.npmjs.com/package/@iran-utils/iranian-banks-vue-icons)

**Card to Sheba** — Fintech utility for validating Iranian debit card numbers and converting them to IBAN / Sheba format. Luhn checksum, IIN/BIN issuer lookup.

[Repo](https://github.com/houtanrocky/cardtoshaba)

**Discord Chat Exporter** — Export Discord conversations into portable formats. Designed for large chat histories.
